# Bean_Pudding_web · 豆格拼豆排版工具

上传图片，出拼豆图项目。

支持72、88、144、221色拼豆色卡，将图片转换为带豆色编号的拼豆图纸，并统计备料用量。采用Vue 3、TypeScript和Vite，所有图片处理均在浏览器本地完成。

完整安装、使用和导出流程见[操作方式](./操作方式.md)。仓库公开供查看、下载和克隆，主仓库的直接写入和管理权限仅保留给仓库所有者。

## 启动

已在Node.js 22.22.1及npm 10.9.4下验证。

```bash
npm ci
npm run dev
```

打开终端输出的本地地址。构建后的静态文件位于`dist/`：

```bash
npm run build
npm run preview
```

## 使用

1. 点击上传区域或拖入PNG、JPG、WebP图片；单张图片最大25MB。页面内置一个可替换的橘子小样。
2. 设置横向和纵向豆数，允许输入正整数，不设固定豆数上限。默认保持原图比例，也可解锁为自由尺寸；提供64/128/256/512颗宽快捷选择。
3. 在“豆色色卡”中选择手头的72、88、144或221色套装，默认221色。点击“生成拼豆图纸”。上传新图时会按当前色卡自动生成一版；修改尺寸或切换色卡后需重新生成，旧图纸禁止导出。
4. 选择“标准”或“细节优先”。细节模式提供锐度和对比度调节，复杂照片默认以256颗的长边生成；像素小样保持标准模式。调节设置后需重新生成。
5. 在中间查看图纸，切换原图对照、编号、网格，或缩放查看细节。大图先显示全图总览，取消“全图总览”后可输入分区行列查看编号。缩放100%表示适应画布。
6. 根据右侧清单备料；支持按编号搜索及按用量或编号排序。
7. 点击“导出整张图纸”默认保存一个完整的编号PNG，不会因超过64格而自动拆分。需要分页打印时，可另选“分区导出”，按每页最多64×64格打包为ZIP，包含编号图纸、总览、全图用量CSV和拼接说明。坐标对应整张图纸，所有分区图例都是整图用量，不能重复累加。也可单独导出CSV。
   整张PNG如果确实无法绘制或编码，会提示使用分区导出；不会自动替换为ZIP或丢弃原图纸。整图直接绘制到最终画布，减少大位图的同时占用。
8. 配色和分区导出均显示进度，支持中途取消；尺寸或处理参数修改后，须重新生成才能导出。

## 配色与统计

- 四套色表分别位于`data/palettes/bead-colors-{72,88,144,221}/`，每套包含JSON、CSV、编号/HEX色卡预览、取样元数据和验证报告。应用直接导入JSON，不另写一套硬编码颜色。
- 72、144色的编号均来自221色，共用相同HEX。88色有76个X系列编号从组合图片取中位色，另外12个编号复用221色；H01、H07等前导零保留在预览、编号、清单中。144色末行经水印上方文字及底色逐格复核为M7、M8、M9、M10、M11、M12、M13、M14、M15。组合图片见`data/palettes/source-multi-palettes.jpg`。
- 每张图纸保存其色卡ID；配色线程和主线程回退均限定在所选色卡，预览、用量、PNG标题及分区说明均根据图纸自身色卡读取。更换设置不会把旧索引解释成新色卡编号。
- 图片通过有界的小画布分块采样，细节模式在大倍率缩小时使用两阶段采样，并在匹配前做亮度锐化和对比度增强。将sRGB转换为D65 CIELAB，使用Delta E 1976选择最近豆色。
- 配色在Web Worker分块计算，主线程仅处理小块采样和结果合并。网格每格使用一个字节存放色号索引，255表示空格；总览最大边为1024像素，编号画布按分区绘制。
- 透明度低于50%的格子留空；其他半透明格子先与白色合成后匹配。全透明图可生成空白图纸和零用量清单。
- 网格数据中的每一项为一个豆色或空格。预览、统计和导出都使用这份网格数据。
- CSV包含UTF-8 BOM，可在Excel等工具中读取中文表头。空格不作为豆色导出。
- 色值取自用户提供的色卡图片；实物颜色请以实际豆子为准。
- “无固定上限”表示没有128/512等业务上限；数值必须可由JavaScript精确表示，总格数和实际容量仍受浏览器及设备内存限制。低豆数无法保存的面部细节需要提高图纸密度，锐度增强不能恢复已丢失的信息。

## 代码结构

| 文件/目录 | 职责 |
| --- | --- |
| `src/App.vue` | 组织页面，协调原图、尺寸、生成及导出操作 |
| `src/components/SourcePanel.vue` | 上传、尺寸输入与比例锁定 |
| `src/components/PatternPreview.vue` | Canvas生命周期、对照、显示开关和缩放 |
| `src/components/UsagePanel.vue` | 用量列表、搜索、排序与导出按钮 |
| `src/composables/useSourceImage.ts` | 图片读取状态、错误、异步竞争和对象URL释放 |
| `src/lib/color.ts` | sRGB/Lab转换和编号文字对比色 |
| `src/lib/palette.ts` | 从四套JSON构建色卡目录，统一查找色卡 |
| `src/lib/pattern.ts` | 网格尺寸、最近色匹配、透明处理、用量计算 |
| `src/lib/image.ts` | 图片解码与Canvas缩放 |
| `src/lib/enhance.ts` | 明暗对比及带边缘邻域的分块锐化 |
| `src/lib/tiles.ts` | 分区布局、取消检查与任务间让出主线程 |
| `src/workers/match.worker.ts` | 复用同一个配色算法的Worker入口 |
| `src/lib/render.ts` | 共享的编号图纸绘制及PNG版面 |
| `src/lib/export.ts` | CSV生成、PNG转换与浏览器下载 |

## 验证

```bash
npm run check
```

依次执行ESLint、vue-tsc类型检查、Vitest测试和生产构建。现有37个测试覆盖标准Lab参考值、四套色卡逐色回匹配、前导零、透明区域、无固定上限的尺寸校验、统计、CSV、输入框交互、色卡切换后的旧图导出阻止、Worker与无Worker回退配色、增强邻域一致性、分区完整覆盖、整图默认导出、显式分区、导出失败提示及取消信号。

新增色卡可用`python3 scripts/extract-palettes.py`重建，再运行`python3 scripts/validate-palettes.py`独立复核；需要Pillow、numpy。复核包含逐色重算、编号数量、CSV/JSON一致性、共用色一致性、预览像素及来源哈希。

仓库包含源码、四套色卡数据、测试和可复现的提取/验证脚本。本地浏览器验收截图、改动审阅记录及大图导出样例保存在`artifacts/`，该目录未纳入Git。
