# 拼豆图片色卡 · 221色

根据用户提供的色卡图片，按从左到右、从上到下顺序核对并提取 **221个带数字的豆色编号**。本目录仅新增数据和预览文件，没有修改应用代码。

## 文件

- `bead-colors-221.json`：直接可用的编号到HEX映射，例如 `palette["A1"]`。
- `bead-colors-221.csv`：同一份色表，包含RGB数值、分组和原图行列位置。
- `bead-colors-221-preview.png`：带编号和HEX的色卡，顺序与原图相同。
- `source-color-chart.png`：用户原始图片的逐字节副本，供日后复核。
- `extraction-metadata.json`：来源哈希、坐标、算法、逐色取样区域与质量统计。
- `validation-report.json`：独立读取生成文件后执行的数据及图像校验结果。

## 取色方法

1. 使用原图自带的sRGB色彩空间；图片尺寸1180×1556，透明度全为255。
2. 在每个色格中取上下两条横向区域，避开文字、小标识、边框和水印。左右各缩进10像素；上条距顶6像素、高6像素；下条距底6像素、高6像素。
3. 合并两条区域，按RGB各通道取中位数，用numpy.rint取最近整数，输出大写`#RRGGBB`。逐色取样948–960个像素。
4. 不把相近色合并，不替换为网上色值，不推断厂家或品牌。

坐标以原图左上角为原点。矩形按`[x1,y1,x2,y2]`记录，包含左上边，不包含右下边。CSV中的行列从1开始。

## 数据使用

JSON的顶层为普通对象，键为字符串编号，值为HEX字符串：

```javascript
const hex = palette["A1"];
```

CSV使用UTF-8（无BOM），列为`code,hex,r,g,b,group,source_row,source_column`。`r/g/b`为0–255的整数，与HEX一一对应。分组顺序为A、B、C、D、E、F、G、H、M；组内按数字递增。

## 准确性说明

这里的HEX代表**这张图片中的近似颜色**，不是厂家官方标准色，也不代表实物在不同光线下的颜色。原图压缩、缩放及显示过程可能影响色值。原图编号已人工核对，颜色值从像素提取；不反推未提供的原始标准色。

取样上下区域的RGB中位数，任一通道的最大差为8/255；该统计反映图片内的局部差异，不代表实物色差的精度保证。详细数值见`extraction-metadata.json`。

## 验证范围

本任务仅生成数据文件和色卡图片，工作区没有现有代码包，因此不涉及代码lint、编译或应用测试。最小验证覆盖JSON结构及字段类型、CSV列及整数类型、221个编号的连续性与唯一性、JSON/CSV/元数据逐项一致性、按原图像素重新计算全部221个HEX、来源哈希、预览尺寸及逐格填充色。完整结果见`validation-report.json`。
